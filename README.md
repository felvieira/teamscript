# TeamScript

> Teams + Transcript — Extraia, pesquise e exporte transcrições de reuniões do Microsoft Teams.

![Chrome Extension](https://img.shields.io/badge/Chrome-Extension-blue?logo=googlechrome)

## Features

- **Extração automática** — captura toda a transcrição com scroll automático
- **4 formatos de export** — TXT, Markdown, SRT (legendas), JSON
- **Busca integrada** — pesquise por texto ou participante em tempo real
- **Preview inline** — veja a transcrição direto no popup com highlight de busca
- **Copiar tudo** — um clique para copiar ao clipboard
- **Estatísticas** — total de entradas, participantes e duração
- **Bilíngue** — suporta transcrições em PT-BR e EN

## Instalação

1. Clone este repositório
2. Abra `chrome://extensions` no Chrome
3. Ative o **Modo do desenvolvedor**
4. Clique em **Carregar sem compactação** e selecione a pasta do projeto

## Como usar

1. Entre em uma reunião do Teams (ou abra uma gravação)
2. Abra o painel de **Transcrição** no Teams
3. Clique no ícone do TeamScript na barra de extensões
4. Clique em **Extrair Transcrição**
5. Pesquise, visualize e exporte no formato desejado
